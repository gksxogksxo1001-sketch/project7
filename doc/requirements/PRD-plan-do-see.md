## 1. 프로젝트 개요 및 배경

### 1.1 개요
본 프로젝트는 과제 6에서 완성된 **'플랜두씨(Plan-Do-See) 다이어리 1'**의 서버 영속화 및 집계 드릴다운 아키텍처 위에, **가입·로그인·로그아웃(자물쇠)**을 붙여 내 계획과 실행 기록을 오직 나만 볼 수 있도록 보호하고, 비인가 접근(401)과 타인 자료 침범(403)이 실제로 거절되는 장면(요청과 응답)을 증명하며, 5일간 실제 사용을 통해 계획 규칙을 개선하는 웹 다이어리 애플리케이션입니다.

### 1.2 핵심 목적
1. **첫 화면 인증 게이트웨이**: 비로그인 상태에서는 다이어리 컨텐츠가 완전히 은닉되고 로그인/회원가입 폼만 노출.
2. **비밀번호 단방향 솔트 해싱**: 평문(Plaintext)은 서버/DB/로그 어디에도 남지 않고 `bcryptjs` 해시(`$2b$10$...`)로 저장.
3. **세션 기반 인증 & 즉각 무효화**: 세션 쿠키(`plandosee.sid`)를 통해 식별하며, 로그아웃 즉시 서버 세션 파괴로 이전 쿠키 재요청 시 `401 Unauthorized` 거절.
4. **완벽한 소유권 격리(양방향 거절)**: 모든 자료에 `user_id`를 바인딩하여 타인의 자료 조회·수정·삭제 요청을 `403 Forbidden`으로 원천 차단하고 목록에도 일절 섞이지 않음.
5. **6번 기존 자료 자동 승계**: 과제 6에서 작성된 기존 다이어리 자료를 유실 없이 첫 등록 계정으로 안전하게 이전.
6. **계정 삭제(회원 탈퇴) 및 데이터 영구 파기**: 탈퇴 시 소유한 모든 계획/할일/실행기록/회고가 함께 완전히 삭제.
7. **5일간 실사용 및 3일차 전 계획 규칙 변경**: 관찰 지표를 고정하고 2일차 뒤 3일차 진입 전에 계획 규칙을 변경하여 오차 지표를 개선.

   - `public/js/app.js` (`handleDeleteAccount`) ➔ `server/api.js` (`DELETE /api/auth/account`) ➔ CASCADE DB 영구 삭제 및 세션 파괴

## 5. 보안 및 비기능 요구사항 (NFR)

1. **비밀번호 단방향 암호화**: `bcrypt.hash(password, 10)`를 사용해 단방향 솔트 해싱 보관 (평문 복원 불가능).
2. **세션 보안**: `httpOnly: true`, `sameSite: 'lax'`, `maxAge: 86400000`(24시간) 설정으로 XSS 탈취 및 CSRF 방어.
3. **환경변수 격리**: `SESSION_SECRET`은 `.env` 파일로 격리하고 `.gitignore`에 등록하여 GitHub 유출 방지.
4. **XSS 방어**: 모든 동적 문자열 렌더링 시 `escapeHtml()` 철저 적용.
